# xwatch

X（Twitter）の公開アカウントを決めた間隔で自動で巡回し、最新の投稿を手元のパソコンに貯めて、ダッシュボードで読むための個人用のツールです。Windows 用です。

- Python 3.9 以上の標準の機能だけで動きます。ほかに入れるものはありません。
- X にはログインしません。ログインしなくても見える範囲（各アカウントの直近の数件）を読みます。
- ダッシュボードは `http://127.0.0.1:8765` で開きます。そのパソコンからしか開けません。

## 入れ方

1. このページの緑の「Code」ボタンから「Download ZIP」を押してダウンロードし、好きな場所に展開します。GitHub へのログインは要りません。
   （git がある場合は `git clone https://github.com/So-Zes/xwatch.git` でも取れます。こちらは `git pull` で新しい版に更新できます）
2. 展開したフォルダの `setup.bat` をダブルクリックします。次のことを順にします。
   - Python 3.9 以上が入っているかを確認します。入っていなければ、入れ方を表示します。
   - パソコンにログオンしたとき、xwatch が窓を出さずに自動で動き出すように登録します。
   - デスクトップに「xwatch」のショートカットを作ります。
   - xwatch を起動して、ダッシュボードを開きます。
3. ダッシュボードの左下の欄に `@名前`（またはプロフィールの URL）を入れて追加します。すぐに最初の取得が始まり、そのあとは決めた間隔で自動で巡回します。

フォルダを別の場所に動かしたときは、もう一度 `setup.bat` を実行してください。

## 使い方

| したいこと | 方法 |
|---|---|
| ダッシュボードを開く | デスクトップの「xwatch」を押します。xwatch が止まっていれば、先に起動してから開きます |
| 止める | フォルダの `stop.bat` を実行します |
| エラーの内容を見ながら起動する | フォルダの `start.bat` を実行します（窓が開いたままになります） |
| スマホから見られるようにする | フォルダの `phone-setup.bat` を実行します（下の「スマホから見る」を見てください） |
| 自動で起動しないようにする | `Win + R` で `shell:startup` を開き、`xwatch` のショートカットを消します |

xwatch はパソコンが動いていて xwatch が起動している間だけ巡回します。スリープ中は止まり、戻ったあとの次の巡回で追いつきます。

## データ

アカウント、投稿、既読とスター、設定、巡回の記録は、フォルダの中の `data/xwatch.db` に保存されます。`data` フォルダを消すと全部なくなります。新しい版に入れ替えるときは、`data` フォルダを新しいフォルダに移してください。

## ダッシュボードでできること

- アカウントの追加、削除、一時停止（最大500件）
- 巡回の間隔の変更（10分〜24時間、最初は30分）、自動巡回のオンとオフ、「今すぐ取得」
- 新しい投稿のお知らせ（画面の中の表示と、許可すればデスクトップの通知）
- 未読の管理（表示したら自動で既読になります）、スター、保存した投稿の全文検索
- 画像、動画のサムネイル、引用された投稿、いいねと表示の数、ダークとライトの表示
- 英語や中国語など、日本語以外の投稿の日本語訳（Google 翻訳）。「原文を表示」で元の文に戻せます。設定の「日本語に翻訳」でオフにできます
- 巡回の記録、エラーの表示、JSON での書き出し
- キーボード: `/` で検索、`R` で今すぐ取得、`U` で未読だけの表示の切り替え

## スマホから見る（Tailscale を使う場合）

[Tailscale](https://tailscale.com/) を使うと、外出先のスマホからも、このパソコンの xwatch を開けます。開けるのは、同じ Tailscale のアカウント（tailnet）につながっている自分の端末だけです。インターネットには公開されません。

1. スマホに Tailscale のアプリを入れて、ログインします。パソコンでも、これと同じアカウントを使います。
2. パソコンで、フォルダの `phone-setup.bat` を実行します。次のことを順にします。
   - Tailscale が入っているかを確認します。入っていなければ、winget で入れるか、ダウンロードのページを開くかを選べます。入れ終えたら、もう一度 `phone-setup.bat` を実行してください。
   - Tailscale にログインしているかを確認します。していなければ、ブラウザでログインの画面が開きます。スマホと同じアカウントでログインしてください。
   - 同じ tailnet の端末からだけ開ける `https://<パソコンの名前>.<tailnet の名前>.ts.net:8443` というアドレスを作ります。tailnet で初めて使うときは、HTTPS を有効にするためのアドレスが表示されることがあります。そのときは、そのアドレスを開いて有効にしてください。
   - スマホで開くアドレスを表示して、クリップボードにも入れます。
3. スマホの Tailscale をオンにして、Chrome でそのアドレスを開きます。メニューの「アプリをインストール」か「ホーム画面に追加」を選ぶと、アイコンから全画面で開けるようになります。

この設定は Tailscale が覚えているので、一度だけで大丈夫です。手で設定するときは `tailscale serve --bg --https=8443 http://127.0.0.1:8765` を実行します。

`tailscale funnel` は使わないでください。xwatch には認証がないので、インターネットに公開すると誰でも操作できてしまいます。

## コマンドライン

```
python xwatch.py --add thsottiaux OpenAI   # アカウントを追加する
python xwatch.py --interval 60             # 間隔を60分にする
python xwatch.py --once                    # 1回だけ巡回して結果を表示する
python xwatch.py --port 9000 --no-browser  # ポートを変える、ブラウザを開かない
python xwatch.py --data D:\xwatch-data     # データの保存先を変える
python xwatch.py --mcp                     # AI 用の MCP サーバーとして動かす（stdio）
```

## AI とつなぐ（MCP と Markdown）

Claude や Codex などの AI から、保存した投稿を Markdown で読めます。普段使う必要はありません。ダッシュボードの設定画面の「AI連携（MCP）」に、そのパソコンの場所が入った設定の例が出るので、コピーして貼るだけです。

| 種類 | ツール | 内容 |
|---|---|---|
| 読む | `get_new_posts` | 前に呼んだときから増えた投稿（最初は直近24時間に取得した分）。多いときは繰り返し呼ぶと続きが出ます。`peek: true` を付けると位置を進めません |
| | `get_latest_posts` | 最新の投稿（`handle` / `hours` / `limit` / `unread_only` / `starred_only`） |
| | `search_posts` | 本文の検索 |
| | `get_post` | 投稿の ID で1件 |
| | `list_accounts` | 追跡しているアカウントと取得の状況の表 |
| | `get_status` | 巡回の間隔、次の予定、数字、最近の巡回の記録、エラー |
| 操作 | `refresh` | 今すぐ取得する |
| | `add_account` / `remove_account` | アカウントの追加と削除（`delete_posts` で投稿も消します） |
| | `set_account_enabled` | 一時停止と再開 |
| | `update_settings` | 巡回の間隔（10〜1440分）、自動巡回のオンとオフ |
| | `mark_read` / `star_post` | 既読とスター |

つなぎ方は次のどれか1つです。

- Claude Desktop（`claude_desktop_config.json`）
  ```json
  {"mcpServers": {"xwatch": {"command": "python", "args": ["C:\\path\\to\\xwatch\\xwatch.py", "--mcp"]}}}
  ```
- Codex（`~/.codex/config.toml`）
  ```toml
  [mcp_servers.xwatch]
  command = "python"
  args = ['C:\path\to\xwatch\xwatch.py', '--mcp']
  ```
- Claude Code など HTTP に対応したもの（xwatch の起動中）
  `claude mcp add --transport http xwatch http://127.0.0.1:8765/mcp`

Markdown を直接読むこともできます: `http://127.0.0.1:8765/feed.md`（例: `/feed.md?handle=OpenAI&hours=48`、`/accounts.md`）

## しくみと注意

- 各アカウントの `https://x.com/<名前>` を取得し、ページに入っているデータから投稿を読み取ります。取れるのは各アカウントの直近の数件のオリジナルの投稿です。巡回の間隔が短いほど取りこぼしが減ります。
- 最大10アカウントを同時に取得し、組の間には数秒の間を空けます。アクセスの制限（429 や 403）を受けたら、そこで残りの取得をやめます。3回続けて失敗したアカウントは、自動で取得の頻度を下げます。
- X のページの作りが変わると取得できなくなることがあります。そのときはダッシュボードにエラーが出ます。
- 翻訳には、Google 翻訳の公開の窓口（`translate.googleapis.com`）を使います。キーもログインも要りませんが、正式に公開されている API ではないので、使えなくなることがあります。そのときは原文のまま表示します。訳すときは投稿の本文を Google に送ります。自動で訳すのは取得してから7日以内の投稿で、それより古い投稿は「翻訳する」を押すと訳します。訳はフォルダの中の `data/xwatch.db` に保存され、検索でも見つかります。
- 鍵アカウントは取得できません。X の利用規約に沿って、個人の利用で、低い頻度で使ってください。
